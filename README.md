# Ms Bible Pro : versions

Ce dépôt contient uniquement les **installateurs Windows** de Ms Bible Pro et le fichier `latest.json` lu par
l'application pour proposer les mises à jour. Le code source n'est pas public.

## Installer

Ouvrez la page [Releases](https://github.com/robin-developpement/ms-bible-pro-releases/releases/latest), téléchargez
`MsBiblePro_<version>_x64-setup.exe` puis lancez-le. Une licence est nécessaire pour utiliser l'application.

## Mises à jour

Ms Bible Pro vérifie au démarrage si une nouvelle version existe et demande avant d'installer
(« Installer maintenant / Plus tard »). Vous pouvez aussi vérifier à la main dans **Paramètres › Licence › Mises à jour**.
La licence, les réglages et les modèles sont conservés.

Chaque installateur est signé : l'application refuse toute mise à jour qui ne vient pas de l'éditeur.
